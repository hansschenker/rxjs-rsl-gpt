# Conformance fixtures

This directory will hold serialized examples used as normative implementation evidence.

```text
fixtures/
  valid/     accepted deterministic RSL documents
  invalid/   rejected documents paired with expected diagnostic codes
```

Fixtures are introduced with the milestone that defines their normalized representation. Until RSL 07 establishes the parser and RSL 06 establishes the model, placeholder YAML would risk inventing syntax prematurely.
